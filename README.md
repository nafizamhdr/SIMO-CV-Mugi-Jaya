# SIMO — Sistem Informasi Monitoring Operasional
### CV Mugi Jaya | Kelompok Maju Lancar

Sistem informasi berbasis web yang mengintegrasikan tiga modul utama:
- **Modul Monitoring Produksi** — Dashboard real-time progres produksi per warehouse
- **Modul Quality Control** — Gate-Out QC digital sebelum pengiriman
- **Modul Logistik & Tracking** — Manajemen vendor, manifest, dan live tracking armada
